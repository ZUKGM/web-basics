ჩვენ უკვე ვიცით როგორ შევცვალოთ ფონტის ზომა, ფერი, სისქე და თავად შრიფტიც კი. ახლა ვისწავლოთ ტექსტის დახრა.

ამისათვის CSS-ში ვიყენებთ თვისებას სახელად font-style. ის ძირითადად გამოიყენება ციტატების, უცხო სიტყვების, ან მნიშვნელოვანი ფრაზების ვიზუალურად გამოსაყოფად.

ძირითადი მნიშვნელობები

font-style-ს ყველაზე ხშირად ორი მნიშვნელობით ვიყენებთ:

  • italic — ტექსტს ხრის მარჯვნივ (კურსივი).
  • normal — აბრუნებს დახრილ ტექსტს ჩვეულებრივ, სწორ მდგომარეობაში.
.quote {
    font-style: italic;
    color: #555555;
}

.normal-text {
    font-style: normal;
}

HTML ტეგები (b, strong, i, em)

გარდა CSS-ისა, HTML-შიც არსებობს სპეციალური ტეგები ტექსტის გასამუქებლად და დასახრელად. დამწყებებს ხშირად ერევათ ისინი ერთმანეთში, ამიტომ მოდი ვნახოთ, რა განსხვავებაა მათ შორის:

გამუქება: <b> vs <strong>

  • <b> (Bold) — უბრალოდ ამუქებს ტექსტს ვიზუალურად, ყოველგვარი დამატებითი მნიშვნელობის გარეშე.
  • <strong> — ამუქებს ტექსტს და თან ეუბნება ბრაუზერს (და საძიებო სისტემებს), რომ ეს სიტყვა ლოგიკურად ძალიან მნიშვნელოვანია.

დახრა: <i> vs <em>

  • <i> (Italic) — უბრალოდ ხრის ტექსტს ვიზუალურად.
  • <em> (Emphasis) — ხრის ტექსტს და ხაზს უსვამს მის მნიშვნელობას (აქცენტს აკეთებს მასზე).
<p>ეს არის <b>უბრალოდ მუქი</b> ტექსტი.</p>
<p>ეს არის <strong>მნიშვნელოვანი</strong> გაფრთხილება!</p>

<p>ეს არის <i>უბრალოდ დახრილი</i> ტექსტი.</p>
<p>მე <em>ნამდვილად</em> მიყვარს კოდის წერა!</p>

ოქროს წესი: თანამედროვე ვებ-დეველოპმენტში უმჯობესია გამოვიყენოთ <strong> და <em>. ეს ეხმარება საძიებო სისტემებს (როგორც Google) უკეთ გაიგონ შენი საიტის შინაარსი, ასევე ეხმარება ადამიანების წამკითხველ პროგრამებს (Screen Readers), რომ ტექსტი სწორი ინტონაციით წაიკითხონ.

🎯 პრაქტიკული დავალება

მოდი გავაკეთოთ ლამაზი ციტატა:

  1. HTML-ში შექმენი პარაგრაფი <p> და შიგნით ჩაწერე რაიმე ციტატა (მაგალითად: "ნუ მიეცემი ოცნებებს და ნუ დაივიწყებ რეალურ ცხოვრებას." - ალბუს დამბლდორი).
  2. მიანიჭე ამ პარაგრაფს კლასი: class="quote".
  3. გადადი CSS-ში და ამ კლასს დაუწერე: font-style: italic;.
  4. შეგიძლია დამატებით font-weight: bold; დაუწერო, რომ ციტატა უფრო თვალსაჩინო გახდეს. შეამოწმე შედეგი Live Server-ით!
