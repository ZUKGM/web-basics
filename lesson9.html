წინა გაკვეთილებში ვისწავლეთ ფერების და ზომების შეცვლა. მაგრამ წარმოიდგინე ასეთი სიტუაცია: შენს საიტზე გაქვს 10 პარაგრაფი (<p>), მაგრამ გინდა, რომ მხოლოდ ერთი მათგანი იყოს წითელი.

თუ CSS-ში დავწერთ p { color: red; }, ყველა პარაგრაფი გაწითლდება. როგორ მოვიქცეთ? სწორედ აქ შემოდის CSS-ის მთავარი იარაღი: კლასები (Classes).

რა არის კლასი?

კლასი არის ერთგვარი "სახელი" ან "იარლიყი", რომელსაც ვანიჭებთ კონკრეტულ HTML ელემენტს. ამ სახელის დახმარებით, CSS-ში შეგვიძლია ვიპოვოთ ზუსტად ის ერთი ელემენტი და მხოლოდ მას შევუცვალოთ დიზაინი.

1. როგორ დავამატოთ კლასი HTML-ში?

კლასის დასამატებლად ვიყენებთ სიტყვა class-ს გახსნილ ტეგში. სახელად შეგიძლია დაარქვა ნებისმიერი რამ (მაგალითად: warning, box, main-title).

<p class="warning">ეს არის მნიშვნელოვანი გაფრთხილება!</p>
<p class="success">ეს არის წარმატებული ოპერაცია!</p>
<p>ეს ჩვეულებრივი პარაგრაფია.</p>

2. როგორ ვიპოვოთ კლასი CSS-ში?

HTML-ში კლასის მინიჭების შემდეგ, გადავდივართ CSS ფაილში. ყურადღება: როცა CSS-ში კლასს ვიძახებთ, მის სახელს წინ აუცილებლად უნდა დავუწეროთ წერტილი (.).

/* წერტილი ნიშნავს, რომ ვეძებთ კლასს სახელად warning */
.warning {
    color: red;
    background-color: yellow;
}

.success {
    color: green;
}

ამ კოდის შედეგად, მხოლოდ ის პარაგრაფი გაწითლდება, რომელსაც class="warning" აქვს. ჩვეულებრივი პარაგრაფი კი უცვლელი დარჩება.

თუ გაქვთ სურვილი რომ კლასი იყოს მხოლოდ ერთი ტიპის ელემენტისთვის განკუთვნილი, ვთქვათ: h4-თქვის, მაშინ შეგიძლიათ ჩაწეროთ:

h4.success {
    color: green;
}

🎯 პრაქტიკული დავალება

ახლა შენი ჯერია, გამოსცადო კლასები:

  1. HTML-ში შექმენი სამი სხვადასხვა <h2> სათაური.
  2. პირველს მიეცი კლასი class="title-one", მეორეს class="title-two", მესამე კი დატოვე კლასის გარეშე.
  3. გადადი CSS-ში და .title-one კლასს მიანიჭე ლურჯი ფერი, ხოლო .title-two კლასს — მწვანე.
  4. ნახე შედეგი Live Server-ით. შეამჩნევ, რომ მესამე სათაური არ შეიცვალა, რადგან მას კლასი არ ჰქონდა!
