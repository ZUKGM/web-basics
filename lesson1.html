გამარჯობა! თუ აქ ხარ, ესე იგი გინდა ისწავლო ვებ-პროგრამირება. ალბათ გგონია, რომ ეს ძალიან რთულია და მათემატიკური გენიოსობა გჭირდება. სინამდვილეში, ვებ-გვერდის შექმნა ბევრად უფრო ჰგავს ლეგოს აწყობას.

მოდი დავიწყოთ ყველაზე მთავარი ენით: HTML.

სახლის ანალოგია 🏠

წარმოიდგინე, რომ აშენებ სახლს.
• HTML არის სახლის ფუნდამენტი, აგურები და კედლები. ის გაძლევს სტრუქტურას.
• CSS (რომელსაც მოგვიანებით ვისწავლით) არის შპალერი, საღებავი და ავეჯი. ის ალამაზებს სახლს.

HTML-ის გარეშე, ვებ-გვერდი უბრალოდ არ იარსებებს. ის ეუბნება ბრაუზერს (Google Chrome, Safari): "აქ არის სათაური, აქ არის ტექსტი, აქ არის სურათი".

როგორ გამოიყურება HTML კოდი?

HTML შედგება "ტეგებისგან" (Tags). ტეგი არის უბრალოდ სიტყვა, რომელიც ჩასმულია < > ფრჩხილებში. აი, ყველაზე მარტივი მაგალითი:

<h1>გამარჯობა მსოფლიო!</h1>

განმარტება

  • <h1> - ეს არის გამხსნელი ტეგი. ის ეუბნება ბრაუზერს: "აქ იწყება დიდი, მთავარი სათაური (Heading 1)".
  • გამარჯობა მსოფლიო! - ეს არის ის ტექსტი, რომელსაც მომხმარებელი დაინახავს ეკრანზე.
  • </h1> - ეს არის დამხურავი ტეგი. დააკვირდი დახრილ ხაზს (/). ის ეუბნება ბრაუზერს: "სათაური აქ დასრულდა".

სულ ეს არის! შენ ახლა წაიკითხე შენი პირველი HTML კოდი. შემდეგ გაკვეთილში ჩვენ ამ კოდს რეალურად გავუშვებთ და დავინახავთ, როგორ გამოჩნდება ის ეკრანზე.
