წინა გაკვეთილში ჩვენ დავწერეთ სათაური და პარაგრაფი. მაგრამ რეალურ ვებ-გვერდებს სჭირდებათ სპეციალური სტრუქტურა, ერთგვარი "ჩონჩხი", რომ ბრაუზერმა (მაგ. Chrome-მა) სწორად გაიგოს ჩვენი დაწერილი კოდი.

ყველა პროფესიონალური ვებ-გვერდი მსოფლიოში იყენებს ამ სტანდარტულ სტრუქტურას.

როგორ გამოიყურება HTML სტრუქტურა?

<!DOCTYPE html>
<html>
  <head>
    <title>ჩემი საიტი</title>
  </head>
  <body>
    <!-- აქ იწერება შენი ტექსტები და სურათები -->
  </body>
</html>

მოდი გავშიფროთ მთავარი ნაწილები:

  • <!DOCTYPE html> — ვეუბნებით ბრაუზერს, რომ ვიყენებთ HTML-ის უახლეს ვერსიას.
  • <head> — აქ იწერება ტექნიკური ინფორმაცია. მაგალითად, <title> განსაზღვრავს, რა ეწეროს ბრაუზერის "ტაბზე" (ჩანართზე).
  • <body> — ყველაზე მთავარი ნაწილი! ყველაფერი, რასაც მომხმარებელი ეკრანზე ხედავს, აუცილებლად <body> ტეგებს შორის უნდა დაიწეროს.

🎯 პრაქტიკული დავალება: ჯადოსნური ღილაკი

ხელით ამდენი კოდის წერა დამღლელია. VS Code-ს აქვს ერთი ჯადოსნური ფუნქცია, რომელიც წამებში გვიწერს ამ ჩონჩხს:

  1. გახსენი შენი test.html ფაილი და წაშალე შიგნით ყველაფერი (ნუ გეშინია!).
  2. ცარიელ ფაილში დაწერე მხოლოდ ძახილის ნიშანი: !
  3. დააჭირე კლავიატურაზე Enter (ან Tab) ღილაკს.
  4. VS Code ავტომატურად დაგიწერს მთლიან HTML სტრუქტურას!
  5. ახლა იპოვე <body> და </body> ტეგები და მათ შორის ხელახლა დაწერე შენი <h1> და <p> კოდები.
