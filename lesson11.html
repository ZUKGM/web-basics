აქამდე ვისწავლეთ ტექსტის ზომის, ფერის და სისქის შეცვლა. მაგრამ შეამჩნევდი, რომ ბრაუზერის სტანდარტული შრიფტი ხშირად უბრალოდ ან ძველმოდურად გამოიყურება.

ვებ-გვერდზე შრიფტის (ფონტის) შესაცვლელად CSS-ში ვიყენებთ თვისებას სახელად font-family.

1. როგორ მუშაობს font-family?

font-family-ს მნიშვნელობად ვუწერთ ფონტის სახელს. პროფესიონალურ კოდში თითქმის ყოველთვის მივუთითებთ რამდენიმე ფონტს (მძიმით გამოყოფილს). ამას ჰქვია Fallback (სათადარიგო) სისტემა.

p {
    font-family: Arial, Helvetica, sans-serif;
}

როგორ კითხულობს ამას ბრაუზერი?

  1. ჯერ სცდის Arial-ს.
  2. თუ მომხმარებლის კომპიუტერში Arial დაინსტალირებული არ არის, გადადის მეორეზე — Helvetica.
  3. თუ არცერთი არ მოიძებნა, გამოიყენებს სისტემის სტანდარტულ უსერიფო ფონტს — sans-serif.

2. მრავალსიტყვიანი ფონტების სახელები

თუ ფონტის სახელი შედგება ორი ან მეტი სიტყვისგან (მაგალითად: Segoe UI ან Times New Roman), ის აუცილებლად უნდა ჩავსვათ ბრჭყალებში:

body {
    font-family: 'Segoe UI', Tahoma, Geneva, sans-serif;
}

3. ძირითადი ფონტების ოჯახები

  • sans-serif: სუფთა, თანამედროვე შრიფტი (მაგ: Arial, Segoe UI). საუკეთესოა ეკრანზე წასაკითხად.
  • serif: კლასიკური შრიფტი (მაგ: Times New Roman, Georgia).
  • monospace: ყველა ასოს აქვს ზუსტად თანაბარი სიგანე (მაგ: Courier New). გამოიყენება კოდის საჩვენებლად.

🎯 პრაქტიკული დავალება

გამოსცადე სხვადასხვა შრიფტი შენს ვებ-გვერდზე:

  1. გახსენი შენი style.css ფაილი.
  2. body სელექტორს დაუწერე: font-family: 'Segoe UI', Tahoma, Geneva, sans-serif;. ნახე, როგორ შეიცვლება მთლიანი საიტის იერსახე.
  3. შექმენი კლასი .code-block და მიეცი მას font-family: monospace;.
