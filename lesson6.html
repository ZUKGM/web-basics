წინა გაკვეთილში ჩვენ ვისწავლეთ ტექსტის დაწერა HTML-ით. მაგრამ, მოდი პირდაპირ ვთქვათ: მხოლოდ შავი ტექსტი თეთრ ფონზე ცოტა მოსაწყენია.

თუ HTML არის სახლის აგურები და კედლები, CSS არის საღებავი, ავეჯი და დიზაინი. ამ გაკვეთილში ვისწავლით, როგორ დავაკავშიროთ CSS ფაილი ჩვენს HTML-ს.

როგორ დავაკავშიროთ CSS?

ამისათვის ვიყენებთ სპეციალურ <link> ტეგს. ის აუცილებლად უნდა ჩავსვათ <head> ნაწილში (და არა <body>-ში!).

<head>
    <title>ჩემი საიტი</title>
    <link rel="stylesheet" href="style.css">
</head>

მოდი გავშიფროთ რა წერია აქ:

  • rel="stylesheet": ვეუბნებით ბრაუზერს, რომ ეს არის სტილების ფაილი (Style Sheet).
  • href="style.css": ვუთითებთ ფაილის სახელს. თუ შენს ფაილს სხვა რამე დაარქვი, აქაც ის სახელი უნდა ჩაწერო.

🎯 პრაქტიკული დავალება

დროა, შენს საიტს ფერები დავუმატოთ!

  1. VS Code-ში, იქ სადაც შენი test.html გაქვს, შექმენი ახალი ფაილი და დაარქვი style.css.
  2. შენს test.html ფაილში, <head> ტეგებს შორის ჩასვი CSS-ის დამაკავშირებელი კოდი (link ტეგი).
  3. გახსენი შენი ახალი style.css და შიგნით დაწერე ეს კოდი:

    h1 { color: red; }

  4. შეინახე ორივე ფაილი (Ctrl+S) და შეამოწმე Live Server-ით. შენი სათაური წითელი გახდება (ფერებს მომავალ გაკვეთილში უფრო დეტალურად ისწავლით).
