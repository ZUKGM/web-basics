ტექსტის ზომისა (font-size) და ფერის (color) შეცვლა უკვე კარგად ვიცით. ახლა ვისწავლოთ, როგორ გავხადოთ ტექსტი სქელი და მკვეთრი, ან პირიქით — თხელი და ელეგანტური.

ამისათვის CSS-ში ვიყენებთ თვისებას სახელად font-weight.

1. სტანდარტული მნიშვნელობები

ყველაზე ხშირად ვიყენებთ ორ ძირითად სიტყვას:

  • bold — ტექსტს ხდის სქელს (გამუქებულს).
  • normal — აბრუნებს ტექსტს ჩვეულებრივ სისქეზე (სტანდარტული).
.important-text {
    font-weight: bold;
    color: red;
}

.normal-text {
    font-weight: normal;
}

2. ციფრობრივი მნიშვნელობები

პროფესიონალურ ვებ-დიზაინში, სიტყვების ნაცვლად ხშირად იყენებენ ციფრებს 100-დან 900-მდე. ეს საშუალებას გვაძლევს უფრო ზუსტად ვაკონტროლოთ სისქე (თუმცა ეს დამოკიდებულია იმაზე, აქვს თუ არა კონკრეტულ ფონტს ამ სისქეების მხარდაჭერა).

  • font-weight: 400; — იგივეა, რაც normal.
  • font-weight: 700; — იგივეა, რაც bold.
  • font-weight: 900; — ყველაზე სქელი ვარიანტი (Black).
.heavy-title {
    font-weight: 900;
}

🎯 პრაქტიკული დავალება

მოდი გამოვიყენოთ წინა გაკვეთილის (კლასების) ცოდნაც:

  1. შექმენი ახალი <p> პარაგრაფი და მიანიჭე კლასი class="highlight".
  2. გადადი CSS ფაილში და დაუწერე ამ კლასს: font-weight: bold;.
  3. დამატებით, შეცვალე მისი ფერი შენთვის სასურველ ფერად.
  4. შექმენი <h1> სათაური და სცადე მისი გათხელება font-weight: normal; გამოყენებით (რადგან სათაურები ავტომატურად სქელია).
