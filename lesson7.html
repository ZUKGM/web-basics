წინა გაკვეთილში ჩვენ დავაკავშირეთ CSS. ახლა ვისწავლოთ, როგორ ვმართოთ ტექსტის ზომა.

CSS-ში ამისთვის ვიყენებთ ბრძანებას font-size. ზომის მისათითებლად ყველაზე მარტივი და გავრცელებული ერთეული არის პიქსელი (px).

(სხვა ერთეულებს მომავალ გაკვეთილში ისწავლით).

როგორ შევცვალოთ ზომა CSS-ში?

ჩვენს style.css ფაილში შეგვიძლია მივმართოთ კონკრეტულ ტეგს (მაგალითად <p> ან <h1>) და მივუთითოთ სასურველი ზომა:

p {
font-size: 18px;
}

h1 {
font-size: 50px;
}

ოქროს წესი: px-სა და ციფრს შორის გამოტოვება (space) არ უნდა იყოს! ყოველთვის წერე 20px და არა 20 px, წინააღმდეგ შემთხვევაში ბრაუზერი კოდს ვერ წაიკითხავს.

🎯 პრაქტიკული დავალება: გავზარდოთ ტექსტი

დროა, ჩვენი საიტი უფრო კითხვადი გავხადოთ:

  1. გახსენი შენი style.css ფაილი.
  2. დაწერე CSS კოდი, რომელიც შენს პარაგრაფს (<p>) გაზრდის 24px-მდე.
  3. შეინახე ფაილი (Ctrl+S) და შეამოწმე Live Server-ით. ტექსტი საგრძნობლად დიდი უნდა გახდეს!
  4. დამატებითი ექსპერიმენტი: სცადე სათაურის (<h1>) ზომის შეცვლაც. რა მოხდება, თუ მას 100px-ს მიანიჭებ?
